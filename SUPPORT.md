# Support

Companion is currently an early-preview open-source project and does not yet
offer a public support SLA.

- For a reproducible defect, open a bug report.
- For usage, deployment, or module-authoring help, start a
  [Q&A Discussion](https://github.com/moxxy-ai/companion/discussions/categories/q-a).
- For a product proposal, open a feature request.
- For a vulnerability, use a
  [private security advisory](https://github.com/moxxy-ai/companion/security/advisories/new).

Include the Companion version, installation method, environment, and the output
of `companion doctor --json` when relevant. The doctor report is redacted, but
review every attachment before posting. Never post API tokens, webhook secrets,
private source, log contents, or production deployment details in a public issue.

Questions belong in Discussions so answers stay discoverable without turning
the issue tracker into a support queue. Confirmed defects and concrete feature
proposals can move into issues from there.
